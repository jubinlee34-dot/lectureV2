# lectureV2 Agent Skills

이 디렉터리는 lectureV2 작업을 위한 경량 운영 스킬을 보관한다.

## 기본 흐름

1. `next-action` — Notion + GitHub 상태에서 다음 작업 후보 3개 제안
2. `scope-lock` — GOAL / SCOPE IN / SCOPE OUT / DONE EVIDENCE 고정
3. `goal-lock` — PLAN → DO → VERIFY 실행 및 완료 증거 확인
4. `pre-push` — push 전 민감정보·위험 변경·검증 상태 확인

모든 스킬은 루트 `AGENTS.md`의 승인 경계를 따른다.
